# Standalone SM8521 CPU adapter

`sm85ops_mame.inc` is the operation table adapted from MAME's `sm85ops.h` by Wilbert Pol. Its original `BSD-3-Clause` notice is retained in the file.

`sm8521_cpu.cpp` provides this separate project's execution state and replaces MAME device/memory calls with `GcMachine` bus calls. It does not include MAME headers, link MAME libraries, launch a MAME process, or require a MAME installation. It has initial DMA, timer/clock, and interrupt support, adapted from MAME callbacks where useful. DMA is serviced during HALT wait cycles; this lets firmware progress from the globe and title splash to the built-in OS/PDA main menu after a longer run. The shared LCD renderer and SDL frontend use MAME-reference VRAM page selection, LCDC enable, pixel packing, palette mode, and colors. Active-low button groups and an approximate 13×10 touch matrix are implemented; the SDL mouse and `gamecom-boot --touch` script map into it. The boot probe also accepts repeated `--button step name duration` events. A scripted touch and button sequence advances Centipede through its title/main menu into the active playfield; left/right moves the shooter and A produces a visible shot in rendered frames. This is an initial short-run compatibility milestone; longer play, collision/scoring behavior, real-time SDL input, and hardware calibration remain unverified. Separate PIO output latches keep the mux stable while input bits are read back; this functional model still needs hardware validation. The renderer produces complete 200×160 frames, but scanline timing/fetch races and physical LCD response are not modeled.

`audio_synth.cpp` is an initial standalone sound-register sampler for SG0/SG1 4-bit wave RAM and the direct DAC, adapted from the supplied MAME reference behavior. It renders mono PCM from register snapshots at frame boundaries; sub-frame writes, SG2, and actual retail-game audio remain unverified. The SDL frontend uses the bundled miniaudio header for host playback, with no separate audio SDK required. It continues silently if no output device can be opened. Gameplay, peripheral details, and undocumented opcodes remain under validation.
