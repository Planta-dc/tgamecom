# Clean-Room Standalone Sharp SM8521 Core & Peripherals

`sm8521_cpu.cpp` and `sm8521_ops.inc` implement a clean-room Sharp SM8521 CPU and on-chip peripheral model with zero MAME code, headers, or runtime dependencies:

- **Clock & core timing**: `5.000 MHz` `phi0` (`10.000 MHz / 2`), `CKC` (`0x1A`) clock prescalers `{16x, 8x, 4x, 2x, 1x, 152x}` committed on `STOP` (`0xF0`), Stop-Free Boot default (`Power` button wake when `STOP` sleep is enabled), 264-byte banked GP register file (`PS0`), hardware `URTS` reset (`0x02`), and 2-byte `DM` (`0x2D`/`0x3D`) instructions.
- **Timers & interrupts**: `5.000 MHz` `phi0` `TM0`/`TM1` prescalers `{1, 1024, 2048, 4096, 8192, 16384, 32768, 65536}` with hardware reload latching, `1 Hz` / `1/60 Hz` `CLKT` real-time clock counter + BCD IRAM mirror (`0x0124..0x0129`), sticky `IR0`/`IR1` vs edge-latched interrupt request tracking, `HALT` wake without `FLAG_I`, and 1-instruction `IRET` deferral.
- **LCDC & DMA**: `320 * 207 = 66,240 phi0` native VBlank (`~75.483 Hz`), live `LCV[7]` VBlank status, 40/50-byte DMA stride (`LCH[5]`), `LCC[0]` 5-pen polarity inversion, hardware-calibrated Game.com STN palettes (`Natural`, `Greenish`, `Grayish`, `High-Contrast`), and chunked `phi0` DMA cycle accounting during `HALT`.
- **Sound (`audio_synth.cpp`, `audio_output.cpp`)**: signed 4-bit `SG0W`/`SG1W` wave channels (`12-bit period + 1` at `5.000 MHz`, immediate step `0`, non-destructive `SGC` enable), 15-bit LFSR `SG2` noise (`init 0x7FFF`), exclusive `SGDA` 8-bit DAC (`(SGC & 0x8F) == 0x88`), cycle-timestamped sub-sample anti-aliasing, ~12.4 kHz reconstruction LPF, and ~4 Hz DC servo.
- **UART & online serial (`serial_link.cpp`)**: `64x` Timer 0 baud division, active-low `P3[3:0]` (`DSR, CTS, RTS, DTR`) hardware handshaking, 2-player `Compete.com` TCP null-modem link cable (`--link-listen` / `--link-connect`), and a 9600-baud Virtual Hayes Modem (`AT` / `ATD` + built-in `GAMECOM.NET` portal + custom `phonebook.ini` TCP dialer).
